使用建议

1不需要全部测。根据你的 Agent 架构、核心任务和产品阶段，选择最值得关注的指标。
2先做最重要的。通常建议从 Outcome 的核心质量指标开始，再补充关键的 Trace 指标。
3指标要能指导优化。当指标发生变化时，你能知道意味着什么，以及下一步应该优化哪里。
4随着 Agent 走向生产环境，再逐步补充更多的指标（如成本、性能、模块级延迟等）。

指标优先级说明
